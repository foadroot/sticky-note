# UI design direction

The visual language is a low-light developer workspace: graphite surfaces, soft contrast, restrained mint for primary action, and mono typography only for shortcuts/status. Every page keeps one clear primary action.

- Landing: explain the capture promise and route directly into sign-in.
- Auth: reduce registration friction while presenting the product value beside the form.
- Workspace: orient with a short headline, clear active/archive state, immediate capture, and scan-friendly cards.
- Projects: concise list first; creation stays inline.
- Project detail: project context is prominent, notes remain the visual focus.
- Settings: one narrow form with explicit copy that changes apply only to future notes.
- Quick Capture: dark overlay, primary textarea, keyboard hints, and secondary controls visually recede.
