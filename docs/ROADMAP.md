# Lightweight roadmap

Future, out-of-MVP possibilities:

- VS Code, JetBrains, CLI, and browser-extension capture surfaces;
- repository, branch, file, line, commit, issue, and URL context;
- optional reminders as a separate concept from note expiration;
- collaboration and sharing; and
- AI-assisted organization.

None of these change the MVP rule: capture quickly, preserve notes, and let organization happen later.
